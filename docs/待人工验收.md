# 待人工验收

这里只记录无法用临时仓库、自动测试或演示界面代替的系统行为；确认后勾选。所有仓库写操作均使用测试仓库，真实窗口调试指定独立的 `SYNCDECK_CONFIG_DIR`。

- [ ] 2026-11-07 开机启动与手动使用：安装本版，在“常规”开启开机启动/托盘，在“同步”关闭自动同步和定时检查。重启电脑应仅进托盘，锁屏、解锁、唤醒不产生自动 commit/push/pull/fetch；手动刷新/同步仍可用。升级旧配置保留原有效规则，新安装总开关默认关闭（来自 docs/plans/2026-11-06-sync-controls-handoff.md）。
- [ ] 2026-11-07 系统触发与冷却：在临时测试仓库打开总开关及对应触发，验证锁屏仅处理待推内容，启动/唤醒/解锁按原规则同步，同类10分钟冷却；关机和睡眠前不再同步，不出现等待同步阻止关机的提示。需要登录的唤醒场景也应只执行允许的一轮（同上）。
- [ ] 2026-11-07 托盘一致性与本地暂停：托盘、主页、设置分别暂停1小时/到本机明天00:00，其他入口立即一致；重启仍有效。已执行轮次可结束，等待中的自动任务及失败重试不开始；到期和手动恢复不立即补跑、不清冷却。总开关关闭与自动检查暂停能同时表达（同上）。
- [ ] 2026-11-07 只读检查：总开关关闭、独立定时检查开启后，真实系统经过30分钟仅fetch/status，工作区、HEAD不改变；暂停后不检查。暂停仓库自动操作仍允许单独检查应用更新（同上）。
- [ ] 2026-11-07 原生退出入口：在测试仓库同步、刷新、提交推送或克隆进行/等待时，分别从设置、托盘、关闭窗口（关闭留托盘已关闭）发起退出，应看到任务说明，可取消且任务继续；明确确认立即退出才中断。留托盘开启时关窗仅隐藏；空闲退出无额外确认。单实例仍生效（同上）。
- [ ] 2026-11-07 自启动失败与补偿：在受限制的Windows用户环境尝试修改自启，确认错误可读且其他设置仍可用；写盘失败且自启恢复失败时提示在系统启动应用中核对。不修改生产配置来制造故障（同上）。
- [ ] 2026-11-07 应用更新实际安装：在可升级的旧安装版中进入“关于与更新”，先下载，切页后进度/包仍在；有仓库任务时不能安装，空闲后安装并重启，设置/项目保留。安装过程不能再接入Git任务。AI仅验证下载/安装分离、mock进度与后端闸门，不实际安装生产更新（同上）。
- [ ] 2026-11-07 Windows通知与托盘状态：自动同步失败/冲突每轮一条通知，手动一键同步无系统通知；成功通知开关有效。刷新/提交/克隆等任务均显示真实忙碌，待确认状态不误称全部最新；Windows休眠/唤醒后托盘暂停截止时间正确（同上）。
- [ ] 2026-10-28 原生目录选择器：从GitHub克隆选择保存目录，取消不改变路径/勾选，选择临时目录后本批用该目录，下批恢复默认。系统原生浏览器入口打开项目主页（来自 docs/plans/2026-10-28-克隆目录与紧凑筛选.md）。
- [ ] 2026-10-21 gh与真实网络：有gh登录时列出私有仓库；无gh/未登录时仅公开仓库且提示明确。使用临时目标克隆公开/私有测试仓库，检查真实Git进度、中文输出、认证失败提示及超时清理仅删除本次新建目录（来自 docs/plans/2026-10-21-从GitHub克隆.md）。
