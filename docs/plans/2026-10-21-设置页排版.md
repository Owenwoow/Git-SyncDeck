# 设置页排版与「退出 SyncDeck」按钮

- 状态：已合并到 `2026-10-21-克隆进度与设置页.md`
- 日期：2026-10-21
- 需求原话：
  1. 设置中后台运行添加可关闭按钮
  2. 设置页面设计存在 ui 上的问题，右边空白了片有点奇怪，参考成熟项目的设计
- 现状：设置页内容最宽 672px（max-w-2xl）且靠左，外层容器（App.tsx 里的 max-w-5xl）却是居中的，所以窗口越宽右边空得越多，两边不对称

```text
/dev-task
【目标】设置页改成"左边分类目录 + 右边只显示当前分类"的排版，整块居中；「后台运行」里加「退出 SyncDeck」按钮
【要做】
1. 布局：左边分类目录（常规 / 网络 / 自动同步 / 提交与合并 / 外观 / 关于），点哪类右边只显示那一类；"目录 + 内容"整块在主内容区居中，最宽约 1000px，宽窗口下左右留白对称
2. 设置项一行一项：左边标题和说明，右边控件（开关、分段选择、按钮、短输入框）；要填较长文字的（默认代码目录、代理地址、提交信息模板、本机名称）放到下一行占满宽度
3. 各类内容：
   - 常规：默认代码目录
   - 网络：联网超时、代理
   - 自动同步：后台运行（开机自启、关窗口时隐藏到托盘、退出 SyncDeck）、离开这台电脑时、回到这台电脑时、检查云端、通知、暂停自动同步
   - 提交与合并：提交信息模板、本机名称、无冲突时自动合并、提交前检查和大文件上限
   - 外观：主题
   - 关于：版本、检查更新、下载并安装
4. 「退出 SyncDeck」按钮：放在「后台运行」那一组；点了彻底退出，托盘图标也消失，和托盘菜单的「退出」是同一个逻辑（后端加一个命令调用 app.exit(0)）；正在同步或克隆时先确认"退出会中断正在进行的同步，确定退出吗？"，没在做事就直接退出；演示模式不真的退出，只弹提示
5. 有新版本时「关于」旁边显示小圆点；启动时更新提示里的「去更新」直接打开设置的「关于」
6. 窗口窄（主侧边栏只剩图标）时，分类目录仍然显示文字；最小窗口 800px 也放得下，不出现横向滚动
7. 每项设置的作用和保存方式（点选即保存、失焦或回车保存）不变，只改排版
8. 文档：docs/requirements.md 3.5 节、README「页面与文件对照」
【不做】
- 「后台运行」总开关（关闭按钮定为"退出 SyncDeck"）
- 一整页滚动 + 目录跟随高亮（VS Code 的做法）
- 设置搜索框：设置项不多
【已定的取舍】
- 一次只显示一类（GitHub 网页版设置 / Obsidian / GitHub Desktop 的做法）：每页都不长，「自动同步」这类设置最多的也不用翻太久
- 「关闭」按钮 = 退出 SyncDeck：不用再去托盘图标上右键；"关窗口时隐藏到托盘"的开关保留
【默认假设】
- 分类按上面 6 类分
- 设置项"左文字右控件"，长文字输入放下一行
- 整块居中，最宽约 1000px
- 有新版本时「关于」显示小圆点，「去更新」直接跳到「关于」
- 窗口窄时分类目录仍显示文字
- 在设置页里切到别的页面再回来，停留在上次看的分类（只记在内存里）；第一次打开显示「常规」
- 退出时正在同步或克隆就先确认，否则直接退出
- 第 3、4 条没有新增设置项；"记住上次填的 GitHub 地址"放在克隆页签里，不进设置页
【验收】
- 演示模式下 1100×720、1920×1080、800×560 三种窗口宽度各截一张图：左右留白对称，没有横向滚动
- 每一类里的每项设置都能修改并保存，成功或失败的提示和以前一样
- 「去更新」能跳到「关于」；「关于」上的小圆点在有新版本时出现
- 演示模式下点「退出 SyncDeck」只弹提示
- npm run build 全绿
- 待人工验收（写进 docs/待人工验收.md）：在真实窗口里点「退出 SyncDeck」，托盘图标消失、进程结束；同步进行中点退出会先确认
【线索】
- src/pages/SettingsPage.tsx：现有的卡片组件都能复用（NetworkTimeoutCard、ProxyCard、SwitchCard、PauseCard、CommitTemplateCard、MergeAndCheckCard、ThemeCard、AboutSection）
- src/App.tsx：main 外层的 max-w-5xl 容器；更新提示的「去更新」
- src/components/layout/Sidebar.tsx：小圆点的样式
- src-tauri/src/tray.rs：MENU_QUIT => app.exit(0)
```
