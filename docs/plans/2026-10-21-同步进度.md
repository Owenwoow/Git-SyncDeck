# 同步进度（参考 GitHub Desktop）

- 状态：已合并到 `2026-10-21-克隆进度与设置页.md`
- 日期：2026-10-21
- 需求原话：后台同步：在后台同步时，我打开了软件，只显示正在后台同步，我不知道到底同步到哪里了。加个功能设计上类似于 github desktop 的功能
- 同批需求：从 GitHub 克隆（`2026-10-21-从GitHub克隆.md`，克隆的百分比进度和这里共用一套 git 进度解析）、设置页「后台运行」加关闭按钮、设置页排版

```text
/dev-task
【目标】后台自动同步和手动一键同步都能随时看到进度（细到 git 的百分比），同步结束后能看到最近一次的结果
【要做】
1. 后端：后台同步把进度推给窗口（现在 autosync.rs 调 run_sync 时传的是空回调）。新增 Tauri 事件（比如 auto-sync-progress），内容和一键同步的 SyncProgressEvent 一样
2. 后端记住正在进行的这一轮的进度快照（已完成的结果、正在处理的项目和百分比），getAutoSyncState 返回它，窗口中途打开时补上
3. git 百分比：fetch / pull / push 加 --progress，边运行边读 stderr，解析出阶段和百分比往上报；白名单允许 --progress；超时、不弹窗、代理等保护不变，子进程仍然只在 git.rs 里创建
4. 主页顶部「一键同步」按钮在同步进行中（后台或手动）变成进度按钮：按钮底色按总进度填充，文字是"后台同步 3/7"或"正在同步 3/7"；标题下一行写"解锁后同步 · 正在推送 Git-SyncDeck 上传 45%"；点按钮打开详细进度弹窗
5. 详细进度弹窗：沿用 SyncDialog 的进行中视图，每个项目一行，显示 等待中 / 正在推送 · 上传 45% / 结果；随时可以关掉，关掉后同步照常进行
6. 手动一键同步也一样：弹窗可以关掉，关掉后进度继续显示在按钮和列表上（改掉需求文档 3.3 节的"不可关闭"）
7. 列表里正在处理的那一行显示"同步中"和百分比，做完立刻换成新状态
8. 后台同步结束后：主页标题下一行写"上次后台同步：10:32 解锁后 · 已推送 2 个 · 1 个需要处理"，点开就是和一键同步结束后一样的结果弹窗，异常可以直接处理（复制给 AI、提交并推送等）；只保留最近一次，存在内存里
9. 托盘悬停文字从"正在同步…"改成"正在同步 3/7"
10. 假数据实现同步加上：演示模式能模拟一次后台同步（带百分比），方便调界面
11. 文档：docs/requirements.md 的 3.3 节和第 7 节、README
【不做】
- 同步记录列表（只保留最近一次）
- 把结果写进配置文件（重启后就没了）
- 定时检查云端（每 30 分钟）显示进度：它只是看一眼
- 取消正在进行的同步：需求文档第 4 节"明确不做"里有这一条，关掉弹窗不等于取消
【已定的取舍】
- 用进度按钮（GitHub Desktop 的样子），不自动弹窗：不打扰，想看再点
- 细到 git 的百分比：要能看出"同步到哪里了"
- 只保留最近一次结果：现在结果只在系统通知里一闪而过，保留一次就够用
- 手动一键同步的弹窗也能关：和后台同步一个样子
【默认假设】
- 进度文字和一键同步共用：等待中 → 正在推送 N 个提交 → 结果，推送 / 拉取时后面加阶段和百分比
- git 的阶段名翻成中文，只显示用户关心的：上传（Writing objects）、下载（Receiving objects）、处理差异（Resolving deltas）；统计、压缩阶段归到"准备中"
- 同时处理好几个项目时，标题下一行写其中一个，后面加"等 3 个"
- 总进度 =（已完成的项目数 + 正在处理的项目各自的百分比之和）÷ 项目总数
- 锁屏时的同步只处理有东西要推的项目，进度里也只列这些
- 等网络重试时显示"等待网络，15 秒后重试 N 个项目"
- 后台同步时「刷新状态」「一键同步」照旧不能点
- 百分比事件要节流（比如每个项目每 200 毫秒最多推一次），免得界面卡
【验收】
- 单元测试：解析 git 进度输出（英文和中文两种，包括用 \r 分隔的行）；白名单允许 --progress、仍然拒绝原来禁止的参数
- 集成测试：用临时仓库跑一次后台同步，能收到逐个项目的进度事件和百分比事件；同步途中查 getAutoSyncState 能拿到已完成项目的结果
- 演示模式：模拟后台同步时按钮变成进度条，点开弹窗能看到每个项目的百分比，关掉弹窗后进度继续；结束后标题下面出现"上次后台同步"，点开能看到结果；手动一键同步的弹窗可以关掉
- npm run build 和 cargo test 全绿
- 待人工验收（写进 docs/待人工验收.md）：真实锁屏、解锁后打开窗口，能看到进度或上次的结果；推送一个大一点的提交时能看到百分比在动
```
