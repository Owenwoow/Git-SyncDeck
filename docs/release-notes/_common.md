**下载**
- `…_x64-setup.exe`：安装程序（推荐）
- `…_x64_en-US.msi`：MSI 安装包

**使用前**
- 需要先安装 [Git for Windows](https://git-scm.com/download/win)，并且 GitHub 登录已保存在凭据管理器里（在终端里 `git push` 不用输密码即可）。
- 安装包未签名，Windows 提示"已保护你的电脑"时，点"更多信息"→"仍要运行"。

**更新**
- 0.2.0 起支持应用内更新：在"设置 → 关于"里检查更新，或等待启动时的提示。直接运行新版安装包覆盖安装也可以，监控清单和设置都会保留。
