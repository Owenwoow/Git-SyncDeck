## 第一个版本

Windows 桌面工具：在一个界面里统一查看多个本地 Git 项目与 GitHub 的同步状态，一键推送或拉取。

- **主页**：所有监控项目的同步状态（已同步、待推送、待拉取、有未提交改动、分叉、未关联云端），需要处理的排在前面；可以搜索、按状态筛选，点开看领先/落后和未提交的文件。
- **一键同步**：待推送的自动推送，待拉取的自动拉取（只做快进）；处理不了的列出原因。
- **异常项目**：复制诊断文本（可以直接粘贴给 AI）、直接提交并推送、本次跳过、打开终端或 VS Code。
- **添加项目**：扫描目录里的 Git 仓库，勾选加入或取消监控。
- **设置**：默认代码目录、浅色/深色主题。
- **安全**：不强推、不 rebase、不 reset、不 stash，不读写凭据，取消监控不删除任何文件。
