## 新功能

- **本次克隆可自选目录**：在“添加项目 → 从 GitHub 克隆”里点击保存位置旁的“更改…”，即可为本批仓库选择其他文件夹。不会修改默认代码目录，克隆结束后下一批恢复使用默认位置。
- **按需筛选仓库**：搜索框旁新增“筛选”菜单，可选择仅看可克隆、隐藏 fork、隐藏已归档。默认显示全部仓库，启用的筛选数量直接显示在按钮上。

## 改进

- **操作栏更紧凑**：路径单独显示，长路径自动省略并可悬停查看；克隆按钮只显示仓库数量，窄窗口也能保持整洁。
- **选择范围更清楚**：搜索和筛选会保留已勾选仓库，底部提示其中被隐藏的数量；全选仅操作当前可见且可克隆的仓库。
- **目录检查随选择更新**：切换保存目录后重新检查本地仓库与同名文件夹，不用重新加载 GitHub 列表；无法克隆的选择会自动移除并提示。克隆进度保留本批实际保存位置，切换页面后仍可查看。
