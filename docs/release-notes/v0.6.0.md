## 新功能

- **同步进度细到百分比，后台同步时也能随时看**（参考 GitHub Desktop）：
  - 同步进行中，主页的「一键同步」按钮会变成进度按钮，底色按总进度填充，写着"正在同步 3/7"或"后台同步 3/7"，点它看每个项目的进度，比如"正在推送 2 个提交 · 上传 45%"。
  - 标题下一行写着现在在做什么，列表里正在处理的那一行显示"同步中 45%"。
  - 一键同步的进度弹窗现在可以随时关掉，同步照常进行；弹窗关着时同步结束，右下角会提示结果，可以点「查看结果」。
  - 后台同步结束后，主页标题下保留"上次后台同步：10:32 解锁后 · 已推送 2 个 · 1 个需要处理"，点开就能处理异常。只保留最近一次，重启后清空。
  - 托盘图标的悬停文字显示"正在同步 3/7"。
- **从 GitHub 克隆自己的仓库**：「添加项目」页新增「从 GitHub 克隆」页签。填你的 GitHub 账号主页、用户名或某个仓库地址，列出账号名下的仓库，勾选后克隆到默认代码目录，带百分比进度，克隆完自动加入监控。
  - 想看到私有仓库，需要先装 GitHub CLI（gh）并运行一次 `gh auth login`；没装时只列公开仓库，页面上会提示。SyncDeck 不读取、不保存你的令牌。
  - 私有仓库克隆时，git 自己也要能登录 GitHub（平时能在命令行里 clone 私有仓库就没问题）。
- **设置页换了排版**：左边是分类目录（常规 / 网络 / 自动同步 / 提交与合并 / 外观 / 关于），一次只显示一类，宽窗口下居中不再右边空一大块。
- **「退出 SyncDeck」按钮**：在"设置 → 自动同步 → 后台运行"里，点了彻底退出（托盘图标也消失），不用再去托盘右键。正在同步时会先确认。

## 注意

- 关掉同步进度的弹窗不等于取消同步，同步会照常做完。
