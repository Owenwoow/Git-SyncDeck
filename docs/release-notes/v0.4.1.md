## 新功能：换电脑时自动同步

- **常驻托盘、开机自启**：关窗口只是缩到托盘。托盘图标颜色：绿 = 都已同步，黄 = 这台电脑有改动还没同步，红 = 有冲突或出错，蓝 = 同步中。
- **离开时自动推送**：关机/重启/注销、锁屏、睡眠时，只推送有东西要推的项目，没有就完全不联网；关机时最多等 30 秒。
- **回来时自动拉取**：启动、从睡眠唤醒、解锁时，把云端的新内容拉下来，顺便补推上次没推完的。同一种自动同步 10 分钟内只做一次。
- **托盘菜单**：立即同步、暂停自动同步到明天；后台同步出错或有冲突时发系统通知。
- 每个时机都能在"设置 → 自动同步"里单独关掉；还可以打开每 30 分钟定时检查云端（默认关，只提示不拉取）。

## 新功能：分叉和冲突

- 本地和云端都有新提交时，先在内存里预演合并：没有冲突就自动合并并推送（可以在设置里关掉）。
- 有冲突就什么都不动，项目标红；在详情里点「复制给 AI」，得到一段现成的提示词，粘贴给 AI 让它教你解决。
- 自动提交改为先在本地提交，再和云端合并；提交前会检查超过 50 MB 的文件和没被忽略的疑似密钥文件（`.env`、`*.key`、`id_rsa` 等），有就不提交并提醒你。

## 改进

- **刷新快多了**：所有项目同时检查，检查完一个显示一个，刷新时列表照常能点；网络卡住时最多等 30 秒；一键同步不再重复检查 1 分钟内刚检查过的项目。
- **代理设置**：自动（git 自己配了代理就用 git 的，没配就用 Windows 系统代理）/ 不用代理 / 手动填写，只对 SyncDeck 生效，不改全局 git 配置。
- **本机名称**：设置里可以填"家里台式机"这样的名字，提交信息里用它代替电脑名。

## 注意

- 更新后默认开机自启，不需要的话在"设置 → 自动同步"里关掉。
- 0.4.0 的发布流程没有跑完，没有安装包，直接安装 0.4.1 即可。
